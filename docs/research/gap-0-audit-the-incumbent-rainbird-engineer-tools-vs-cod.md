# Gap research: Audit the incumbent 'rainbird-engineer-tools' VS Code extension and any other existing RBLang editor tooling

Publisher: "tom-sherman" (display "Tom Sherman") — a personal publisher account, NOT Rainbird Technologies Ltd; flags "verified" but isDomainVerified=false. CRITICAL POSITIONING FACT: its package.json contributes NO language and NO grammar — only (a) one command `extension.rbTools` (a QuickPick offering createConcinsts / createFacts / createFactsFromTable, the latter using csv-parse) and (b) 11 snippets attached to the generic "xml" language (prefixes: rb, relinst fact, relinst rule, concinst, condition, concept, rel, condition:expression, condition:expression:value, datasource, import). So it provides zero RBLang syntax highlighting, zero validation, zero file-type association. RAINBIRD STUDIO'S OWN EDITOR (reverse-engineered from public JS bundles). app.rainbird.ai is a CRA/React app (v4.118.0, commit 258b11cc per /env.js). The RBLang code panel is NOT CodeMirror/Monaco in the main app: it renders an <iframe id="v2RBLangIframe" title="editor" src={V2_URL+"/editor"}> where REACT_APP_V2_URL=https://legacy.app.rainbird.ai — i.e. today's code panel is the LEGACY AngularJS editor embedded in an iframe (a strong "official tooling is stale" argument). That legacy app (legacy.app.rainbird.ai/dist/app.min.js, publicly fetchable) uses ACE with a custom mode "ace/mode/rblang" comprising: (1) rblang_highlight_rules — a keyword-mapper grammar (elements meta|concinst|relinst|funct|rel|concept|condition|expression|firstForm|secondFormObject|secondFormSubject|compound|datasource|action|input|headers|header|import as "keyword"; attributes behaviour|allowUnknown|allowCF|subject|object|name|plural|askable|value|type|cf|salience|scope|canAdd|hostname|path|map|method|weight|key|km|username|versionNumber|minimum|rule|certainty|group|alt as "constant.language"; comment regex "--.*$"); (2) rblang_worker running a bespoke ~45KB linter (rblint) that checks duplicate concinsts/facts, unknown concept/relationship types, subject/object type agreement, date/number/truth literal validity, datasource %S input types, and resolves imported KMs via /kb_man/editorResources; (3) a contextAwareCompleter that infers the enclosing element (relationship/rule/concept/datasource/instance/header/meta/compound) by scanning preceding lines and serves per-context element+attribute completions (filtering attributes already present) plus expression-function vs expression-operator completions inside expression="..." attributes; (4) an official Ace snippet catalog ("ace/snippets/rblang", scope rblang) — the canonical list the VS Code extension "mirrors", including relinst rule/fact/compound, condition, expression(+value), sumObjects, countRelationshipInstances, isSubset, concept + 3 datasource variants (incl. POST+CDATA), concinst (+markdown meta), relationship (+question text), meta, cdata, firstForm/secondFormSubject/secondFormObject, datasource, action, input, headers/header, compound, markdown image/link snippets, and import/link-km variants. All extracted VERBATIM to /Users/julio/rblang-research/: rainbird-studio-ace-rblang-mode.js, rainbird-studio-ace-rblang-snippets.js, rainbird-studio-contextAwareCompleter.js, rainbird-studio-completions.js (all 22 completion constants incl. 25 expression functions and 6 NL comparison operators), rainbird-studio-rblint-worker.js. Additionally the CURRENT Studio main bundle embeds a full RBLang structural schema (element nesting + required/optional attributes + value validators, e.g. relinst optional attrs include minimum-rule-certainty, alt, name; concept behaviour accepts mutually-exclusive|mutex|mx; canAdd enumerations) used by parseKM — saved to rainbird-studio-rblang-structural-schema.js; this is a ready-made spec for a VS Code language server. Note the legacy completer's function list (25 date/aggregate functions) predates the 2025-26 changelog additions (includes(), minObjects(), maxObjects(), isWithinRange(), startsWith(), endsWith(), joinObjects(), regexCount()), so the official code panel's autocomplete lags the engine — another gap to exploit. Also: the namespace URI http://rbl.io/schema/RBLang serves NO schema — rbl.io's TLS cert now belongs to neronote.com (domain apparently lapsed), so any extension must ship its own schema.

OTHER RBLANG TOOLING (exhaustive sweep of GitHub repo search, npm, open-vsx, marketplace, web): (1) Mat-Rig/rblang-extract (JS, ~2021, 0 stars) — parses RBLang and tabulates rels/concepts with CSV export; (2) tom-sherman/rainbird-api-js + npm rainbird-api 1.3.1 (2019); (3) official Rainbird code: gitlab.com/rainbird-ai public projects are sdk-js (active, last activity 2026-07-14), sdk-go, sdk-demo, rbdat (2021), 3rd-party-connectors/rainbird-crewai-tools (2025-02); npm @rainbird/sdk 1.5.9, @rainbird/sdk-react, @rainbird/sdk-react-material (all 2026-06-23), @rainbird/yolapi — all runtime/API SDKs, none editor tooling; GitHub org RainBirdAi has no IDE tooling (npm rainbird-linter 2015 is a JSHint wrapper, unrelated to RBLang). NO tree-sitter, Vim, Sublime, Emacs or IntelliJ RBLang support exists anywhere findable. Marketplace name collision: kraken.reindeer-basic-language-support says "RBLang support" but means "Reindeer Basic" — unrelated. Grep.app blocked by bot checkpoint; GitHub code-search API requires auth (couldn't run "rbl:kb" code queries, mitigated via repo/topic/npm searches).

RAINBIRD'S OWN IDE INTENTIONS: no public statement, blog post, changelog entry, forum announcement, or LinkedIn post announcing VS Code/IDE tooling was found. docs.rainbird.ai's RBLang reference says RBLang "is generated by Studio and Co-author" and users "can inspect and edit it in the code panel when you need low-level control" — the in-browser panel is the only sanctioned editing surface. The 2020 platform-upgrade blog explicitly de-emphasizes RBLang ("you don't need to learn the coding language"). Current investment direction per changelog 4.82-4.118 (2025-26) and Rainbird Labs: Co-author LLM copilot (open beta since 4.98.0, Nov 2025), Generate-from-Docs, Rule Tracker (tracker.labs.rainbird.ai), a fine-tuned graph-generation LLM with Python APIs, and an "Agentic Knowledge Engineering" Claude Skill (rainbird-graph-creation, distributed as a ZIP via the Rainbird forum, builds/uploads/tests graphs via API and "fixes syntax errors automatically") — i.e. AI-assisted authoring, not IDE tooling. The forum (forum.rainbird.ai) is a Circle.so community behind Cloudflare (not publicly searchable). Net: the field is completely open for an official VS Code extension; the only prior art is one abandoned 2019 third-party snippets extension with 455 installs, and Rainbird's own richest editor assets (Ace mode, linter, context completer, snippet catalog, structural schema) are publicly extractable and now saved locally for reuse.
