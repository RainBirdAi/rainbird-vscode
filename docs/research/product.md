# Research: product

Rainbird (Rainbird Technologies Ltd, founded 2013 in Norwich, UK by James Duez, CEO, and Ben Taylor, CTO; company no. 08599568) is a decision-intelligence/automated-reasoning platform now positioned as "deterministic AI for regulated decisions" and "decision automation for regulated work" — explicitly the "decision layer for agentic AI" with no LLMs in the decision loop.

CORE TECHNOLOGY. Domain expertise is encoded as "Knowledge Maps" (marketing increasingly says "knowledge graphs"): extended knowledge graphs of Concepts (typed containers: string, number, date, truth; only strings can be relationship subjects; strings support a mutually-exclusive two-instance mode), Relationships (directional subject→object, singular or plural, optionally askable with configurable question forms), Facts (subject>relationship>object triples each carrying 0–100% certainty; global map facts vs session-local facts from inject/datasource/rule/answer/synthesised sources), and Rules (conditions over relationships plus expressions; header defines the inferred fact and a maximum certainty cap defaulting 100%; conditions have weights relative to each other, mandatory/optional behaviour, and ordering modes Default/Top Down/Top Down Strict; minimum rule certainty defaults to 20%). The symbolic inference engine is backward-chaining and goal-driven: a query is a triple with a missing part (object query "Mike speaks ?", subject query, or certainty query), and each condition is resolved via the Match→Infer→Ask (MIA) process: match existing facts, else fire rules to infer, else ask the user (24-hour response window per question). Certainty is explicitly a confidence score, not a probability; per-condition impact = weight × underlying fact certainty, impacts sum (rounded) to the inferred fact's certainty, capped by rule certainty — visualised in the Salience Chart. Rules support natural-language "evidence text" with {{%VARIABLE}} substitution. Expressions include comparison, math, string (includes/startsWith/endsWith/regexCount), date arithmetic, and list functions (countRelationshipInstances, sumObjects, min/maxObjects, joinObjects). Every decision yields an Evidence Tree — colour-coded fact provenance (rule, list-function, inject via API, user answer, datasource, hard-coded map fact) with per-fact certainty, expandable rule conditions, and salience view — accessible in Studio, via shareable link, or recursively via API using factIDs, optionally secured with an x-evidence-key (256-bit encryption by default).

AUTHORING. Rainbird Studio is the no-code web authoring environment (community login app.rainbird.ai; enterprise enterprise.rainbird.ai) with visual graph editing, auto-save, undo/redo, markdown metadata, and a code panel exposing RBlang — the underlying XML knowledge language (elements: concept, rel with askable/plural/allowCF/allowUnknown/canAdd/group attributes and firstForm/secondFormSubject/secondFormObject question templates; concinst; relinst for facts and rules with cf, name (Named Rules, ~Dec 2025), alt evidence text, condition elements with rel/expression/weight/behaviour/value). Datasources are REST API integrations (GET/POST, variable-substituted headers, JSONPath response mapping into facts). Import/export uses .rbird files (map code + layout + readme; excludes versions/tests/agents/stats). Versioning: single editable draft, immutable auto-incrementing numbered versions, restore-by-copy rollback, one version flagged Live. Testing tools: Quick Query (manual), NL test agent (beta; exercises /interact and /explain from Studio), Automated Tests (recorded query/answer scripts with expected results, Run All regression runs, results-only via inject or end-to-end), and external UAT. Stats & Reporting gives query usage metrics, CSV export, and opt-in per-version interaction history. A Library ships Templates (domain-specific), Patterns, and Mechanisms. GenAI-assisted authoring (Anthropic models via AWS Bedrock, EU processing, ISO27001): Co-author (Plan/Edit/Ask modes; builds/edits graphs from up to 6 docs / ~50k words TXT/PDF/CSV), Consult (knowledge elicitation interviews), Generate-from-documentation, all open beta since ~Nov 2025.

CONSUMPTION. Decisions API (community base https://api.rainbird.ai, enterprise https://enterprise-api.rainbird.ai, X-API-Key auth): GET /start/{kmID} (optional version/useDraft) → session; POST /{sessionID}/inject (≤250 facts/batch); POST /{sessionID}/query {subject, relationship, object?} → question or result loop via POST /{sessionID}/response (answers can carry certainty 1–100, yes/no for first-form); evidence at GET /analysis/evidence/{evidenceKey}/{sessionID} and per-factID recursion. Beta NL APIs: /interact (natural-language, fact extraction against the graph, multi-turn sessions, responseType question/result/error) and /explain (LLM-generated narrative of the evidence tree via Anthropic on Bedrock, per-factID). SDKs: JavaScript (@rainbird/sdk, @rainbird/sdk-react, @rainbird/sdk-react-material) and Go; marketing also claims Python/Java. Other consumption: published Agents (configurable branded web Q&A UI, shareable link or iframe embed, optional evidence/certainty display), Workflow Designer (Studio tool triggering multi-map workflows from external systems), connectors for UiPath (marketplace listing), Blue Prism, Microsoft Power Automate, and MCP — knowledge graphs exposed as MCP tools for AI agents (query/explain tool calls returning outcome + certainty + evidence tree); MCP is marketed but not yet in the docs portal. Hosting: free Community SaaS (non-commercial production), Enterprise SaaS (HA, SSO/2FA, shared workspaces, SLAs), Rainbird-managed private AWS environment, self-hosted AWS, or on-prem Kubernetes. ISO 27001 certified, HIPAA compliant claim.

PACKAGING/NAMING (2025–2026 repositioning). Product family now: Rainbird Studio, Rainbird Reasoning Engine, Rainbird Foundry (enterprise programme encoding a whole policy estate / "Computable Policy"), RAKE — Rainbird Agentic Knowledge Engineer (closed-beta agentic workbench converting policy documents into deployed decision agents through research→build→evals→expert sign-off in Studio→deploy via MCP/API; free in Community during beta, BYO Anthropic/Bedrock key), and the Rainbird Claude Skill (Rainbird Labs "Agentic Knowledge Engineering" skill: Claude researches, builds, live-tests via API and documents graphs; ZIP from Labs Forum). Pricing tiers: Community (free, non-commercial), Business (annual per decision service; production REST+MCP, Foundry, graded evals in CI/CD, ModelOps), Enterprise (custom; private/self-hosted, SSO, SLAs, Computable Policy programme). Billing unit = one decision-service call returning outcome+certainty+evidence tree. 23+ downloadable Use Case Accelerators across Banking (KYC/CDD, transaction monitoring, sanctions screening, APP fraud reimbursement, BSA/AML-OFAC, mortgage underwriting, adverse action, trade finance), Financial Services (FCA Targeted Support PS25/22, Consumer Duty suitability, redress, GENIUS Act stablecoin), Insurance (underwriting, motor/property claims, credit hire), Tax & Audit (UK-US double taxation, global mobility payroll, lending file audit), Healthcare (prior auth, claims adjudication, Medicaid/Medicare eligibility). Customers: EY, BDO (5 hrs saved per R&D tax claim), DAC Beachcroft (800% more fraud detected), Klick Health (MLR review −16 days), Killik & Co, NHS trust (Covid risk assessment), a global credit-card provider (85% fraud-case automation). Funding is modest (~$5.1M total; £2.286m seed Sep 2022 — Eden Rock, QVentures, Techstars); ~$3M ARR (2024, est.). Platform version 4.106.0 as of Mar 2026; docs on GitBook at docs.rainbird.ai with llms.txt index and .md endpoints.
