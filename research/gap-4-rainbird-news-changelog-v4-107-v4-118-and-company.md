# Gap research: Rainbird news, changelog v4.107-v4.118, and company status 2025-2026 (retry of failed news thread)

CHANGELOG DELTA (v4.107→v4.118). The core finding is that no public changelog exists for any release after v4.106.0. The docs changelog (https://docs.rainbird.ai/rainbird/whats-new/change-log.md) still tops out at 4.106.0 (Community 2026-03-05, Enterprise 2026-03-12) as of 2026-09-01, while GET https://api.rainbird.ai/version returns 4.118.0. A Wayback snapshot of the changelog from 2026-05-21 also topped out at 4.106.0, so Rainbird stopped publishing release notes after March 2026 — 12 releases (~biweekly cadence, so 4.107≈mid-Mar through 4.118≈late Aug 2026) are undocumented. Indirect evidence of what shipped in the window: (1) A new 6-page "RBlang reference" docs section (xml-structure-and-namespaces, concepts-relationships-and-instances, rules-and-expressions, functions-reference, datasources-reference, validation-checklist-and-examples) was added between 2026-06-10 and 2026-09-01 (absent from the Jun 10 Wayback nav, zero Wayback captures). It codifies the current grammar: root <rbl:kb xmlns:rbl="http://rbl.io/schema/RBLang">; elements concept/rel/concinst/relinst/condition; rule (relinst) attributes type, object, cf, alt, name (name ≤170 chars, non-unique — Named Rules, which actually shipped in 4.101.0, 2025-12-17); condition attributes rel/subject/object/expression/value/weight/behaviour(mandatory|optional); alt text with {{%VAR}} interpolation; assignment only via value= (never "="); 'truth' boolean type; single-quoted string literals; and a full function catalogue (isWithinRange, includes, startsWith, endsWith, regexCount with ECMAScript '/pattern/flags', round/ceil/floor/abs/min/max/mod/pow/sqrt, today/now/add*/subtract*/…Between/isBefore-Same-AfterDate, countRelationshipInstances/sumObjects/minObjects/maxObjects/joinObjects/isSubset, and/or). No RBLang grammar changes after 4.106 are evidenced; the last confirmed grammar changes are Named Rules and multi-operator bracket calculations (both 4.101, note: left-to-right evaluation, NOT PEMDAS). (2) Docs were restructured: in the 2026-03-16 snapshot, Rainbird Labs contained co-author/consult/explain/generate-from-documentation/interact/nl-test-agent; by 2026-06-10 those had moved into the main docs (Beta APIs /nl/interact + /nl/explain under developer-docs; NL test agent under Testing) and Labs became: Agentic Knowledge Engineering Claude Skill (Pilot; 'rainbird-graph-creation' ZIP distributed via forum.rainbird.ai; page recommends Opus or Fable; create-only uploads; 1–2h builds), Rule Tracker (Pilot, tracker.labs.rainbird.ai), Bulk Document Extraction Pipeline (R&D). (3) The JS SDK (@rainbird/sdk) went from dormant (1.4.42, 2025-09-23) to a burst: 1.5.0 (2026-04-30) → 1.5.9 (2026-06-23); GitLab commits (rainbird-ai/sdk-js) show the work was a "New Standard Agent" embeddable component (tickets RB-8024/8026/8034/8101–8146), implying a new published-agent UI shipped platform-side in the window. (4) The marketing site was rebuilt and now sells features absent from docs: "Production REST API and MCP endpoint", "Graded evals in your CI", "ModelOps: who changed what, when and why", "Foundry for agentic knowledge engineering" (Business tier), plus 25+ downloadable regulated-decision "accelerators" with locally runnable evals (Community tier). GitBook's own ask-API answers that the docs contain no MCP documentation — a confirmed docs/marketing gap. Current documented API surface (unchanged): X-API-Key header auth (legacy BasicAuth still supported); api.rainbird.ai / enterprise-api.rainbird.ai; GET /start/{kmID}?useDraft|version, POST /{sid}/inject|/query|/response|/undo, GET /version, beta POST /nl/interact (Version:v1 header) and /nl/explain; OpenAPI 3.1 embedded in docs (info.version 1.2.0). There is NO documented API for uploading/importing RBLang (Studio-only import/export), yet the Claude Skill uploads graphs and "fixes syntax errors automatically" — an undocumented endpoint must exist.
