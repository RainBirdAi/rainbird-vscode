# Run a query

With an `.rbl` file open, run **Rainbird: Run Query…** (or the ▶ button in the editor title bar):

1. Pick a **goal relationship** from your map
2. Optionally provide a **subject**
3. Answer the questions the engine asks — the extension drives the full Match → Infer → Ask loop
4. Get the **result with certainty**, then click through to the **evidence tree** showing exactly how the engine reached it

The evidence tree needs the map's **Evidence Tree Link** enabled (Studio → Publish → API Management → Access Control).
