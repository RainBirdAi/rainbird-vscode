# Connect to Rainbird

Pick your environment (Community `api.rainbird.ai`, Enterprise `enterprise-api.rainbird.ai`, or a private URL) and paste your API key — it's stored encrypted in VS Code's SecretStorage, never in settings files.

Use your Platform API key, the same key Rae uses: it is on your **Account** page in Rainbird Studio (Rae's **Settings → API keys** links to it) and on any model's **Publish** page there. In the next step you will also need the model's **kmID** (Knowledge Map ID), from the project's **Connect → API** tab in Rae.
